# Tempo Examples

A simple, kid-friendly web audio player for the Tempo Examples track.

## Live site

After GitHub Pages is enabled, the site will be available at:

`https://<your-github-username>.github.io/x_tempo_example/`

## Local preview

Open `index.html` in a browser, or run a local server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## GitHub Pages setup

1. Push this repo to GitHub as `x_tempo_example`.
2. Open the repo on GitHub.
3. Go to **Settings** → **Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
5. Choose the `main` branch and the `/ (root)` folder.
6. Save. GitHub will publish the site in about a minute.
